# Trazabilidad de requisitos CU01–CU06

Fuente: `CU_Marketplace.xlsx`, hojas `UC-01` a `UC-06` y `Requerimientos`.
SHA-256 del archivo revisado: `476eadcb89905d3c2ab5d106f3a9a1b500fb1a2c1eeaab3c99812574b3dac199`.

Esta matriz audita las suites de este repositorio, no la cobertura de todas las pruebas del backend. **Con prueba** significa que existe una aserción de integración para el criterio de backend; su resultado se consulta en Surefire. **Parcial** conserva condiciones pendientes. **Sin prueba** identifica trabajo pendiente, sin atribuirle cobertura. Los contratos de aceptación se ejecutan y pueden revelar incumplimientos reales.

No se asigna un porcentaje de cumplimiento a partir del número de tests. Los RNF de rendimiento, usabilidad, accesibilidad y calidad de IA requieren verificaciones específicas; estas suites no los certifican. Los escenarios del navegador no se consideran cubiertos por una petición MockMvc.

Las suites ampliadas de IA, alertas, reseñas, direcciones y pasarela adaptan escenarios de integración ya existentes en Transformers-AS (`263bd0e`), con nombres propios en este repositorio. No se copia producción. Combinan peticiones MockMvc y llamadas a servicios reales con MySQL. Solo se simulan sistemas externos: Gemini mediante WireMock, Mercado Pago mediante un spy y notificaciones mediante el gateway simulado del backend.
